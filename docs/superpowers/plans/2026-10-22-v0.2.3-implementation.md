### W8 · B-4：发布数据回流 MVP（中，含裁决点）

- **MVP**：成片卡「录入发布数据」入口（平台/链接/播放/完播/点赞手录）→ `export_jobs` 新列 JSON → 成片列表展示数据列。**API 自动抓取不做**（平台官方无公开 API，爬取有合规风险）——若业主要自动抓取需另行裁决数据来源。

### W9 · B-5：人脸 9:16 裁切（gate：评估 → go/no-go）

- **评估 spike（时间盒半天）**：opencv（已在依赖）人脸检测在真实剧集素材上的检出率/漏检代价；9:16 裁切对双人同框/无脸镜头的降级策略。
