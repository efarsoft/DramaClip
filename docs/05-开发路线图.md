## W1 · 骨架与通信（当前阶段）

### 任务分解

1. **基线**：backup 物化（✅ 已完成）、根配置、目录骨架；
2. **protocol/**：schemas（common + system）+ ts 类型与 METHOD_NAMES；
3. **service/**：
   - transport：连接客户端（管道/UDS 双路 + 行分帧）、rpc 信封与路由、notify；
   - api/system.py：ping / health / shutdown；
   - infra：paths（数据目录）、storage（db + 001_init 迁移 + settings repo）、jobs（状态机）、config（默认值）；
   - tests：信封 roundtrip / 路由分发 / 行分帧 / 契约同步 / 迁移幂等；
4. **desktop/main**：ndjson（纯函数）、pipe-server（监听+认证+请求转发+通知）、restart-policy（纯状态机）、service-manager（spawn+握手+心跳+重启+退出）、ipc、preload；
5. **desktop/src**：App/路由/深色主题/providers、home 状态页（显示 app 版本 + 经 Python 往返的 service 版本）、client.ts、ui store；
6. **scripts/dev.mjs + ci.yml**；
7. `npm install` + `.venv` 建立 + 三道门禁全绿 + 提交。

### DoD

- [ ] `npm run dev` 一键拉起应用，状态页显示 service_version（经管道真实往返）；
- [ ] 手动 kill Python 进程 → 自动重启并恢复连接（≤3 次退避）；
- [ ] CI（lint / typecheck+mypy / test）全绿；
- [ ] 握手失败（错误 token）连接被拒绝。

## W2-W4 · P0 最小闭环

### W2 第一层分析引擎 ✅（2026-09-05 完成）

- infra/ffmpeg：runner（超时/取消/-progress 解析，含 ffmpeg out_time_ms 实为微秒的怪癖处理）、probe、binaries 解析；
- engines/analysis：transcriber（faster-whisper 默认✅ / SenseVoice 懒加载就绪未装）、scene_detector（PySceneDetect + 规整洁函数）、audio_analyzer（wave+numpy 核心，BPM 可选 librosa）、pipeline、runtime 懒加载单例；
- api：project（create/list/get/delete/scan_episodes 自然排序）+ analysis（start/status/cancel/results 长任务 job 模式，单集失败不中断）+ RpcDomainError 分段错误码 + AppContext 依赖注入；
- storage：projects/episodes/analysis 三仓储 + 002 迁移（audio_features 列）。

**DoD 已验证**：真实单集（TTS 语音合成视频）经 RPC 全流程分析——扫描 18.9s → 进度 2→20→55→75→100 推送 → 4 段中文 ASR 落库。发现并修复：SQLite 跨线程（check_same_thread=False）、ctranslate2 auto 设备缺 cublas（asr.device 默认 cpu）、hf-mirror 不可达（复用本地 HF 缓存 + HF_HUB_OFFLINE）。
**顺延**：filters.py（滤镜链构建）移至 W4 随编码管道一起落地，避免无消费者的死代码。

### W3 第二层精简 + 分析看板

- engines/semantic：llm_client（OpenAI 兼容抽象）、conflict、ranker、genre；
- 前端：工作台（统计概览/最近项目/系统状态）、项目管理页、分析页（两阶段交互全流程）；
- api 完善 project/analysis 全套 + project.rename / duplicate / dashboard_summary。

**DoD**：UI 导入 3-5 集 → 全量分析 → 看板展示高光列表与情绪曲线；无 LLM Key 时降级关键词打分不阻塞。

### W4 两种模式出片 ✅（2026-09-05 完成）

- engines/narration：models（plan_data 结构）+ modes（raw_clip 冲突开场编排 / intro 片头段）+ pipeline（intro 文案模板降级 + edge-tts 引子合成回填时长）；
- engines/exporter：encoder 两阶段（段级切割：竖屏 1080×1920 + 消重微变速/微缩放/eq + 遮罩 + 旁白混音 → concat 拼接 + `-map_metadata -1`）；
- engines/dedup（jitter/params，参数=经验参数表）+ subtitle/mask + tts（edge，云端无需模型）；
- api/narration + export（job 模式）；前端：模式配置（8 卡分组）/生成导出（编排列表+时间线条带+逐方案导出）/导出管理（成片列表+预览）三页；
- dramaclip:// 预览协议：**必须 `standard: true`**（media pipeline 只走标准 scheme）+ Range/206 字节切片。

**DoD 已验证**：真实短剧两模式出片——raw_clip 7 段 37.1s、intro_narration 22 段 187.8s（edge-tts 旁白 9.2s 混音），均 1080×1920 H.264/AAC；导出管理页 dramaclip:// 预览播放成功。发现并修复：应用壳整页滚动致侧边栏滚出视口（height:100vh 修复）。
**遗留优化**：预览协议整文件读入（≤百 MB 可接受，大文件改流式）；intro 时长截断参数微调；Pydantic 序列化 warning 清理。
