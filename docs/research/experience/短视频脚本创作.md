# 短视频脚本创作

## 一、爆款脚本四要点

| 要点 | 说明 |
|---|---|
| 立意 | 立意不同，带给观众的感受不一样。内容尽量积极清晰，避免空泛啰嗦——时长一长就容易让人看累。 |
| 风格 | 短视频表现风格很多，尽量挑选贴合赛道的方向，更容易做出鲜明特点。 |
| 节奏 | 各平台不缺短视频，想留住观众，开头节奏一定要抓人——能不能在 3 秒内吸引注意非常关键。 |
| 框架 | 3 秒抓眼、8 秒反转、7 秒停留、中段 8 秒循环推进。 |

## 二、节奏公式（时间轴口径）

| 时间点 | 要求 |
|---|---|
| 3 秒抓住注意 | 前 3 秒的画面先把兴趣勾起来，抓住观众目光和好奇心，让他们愿意继续往下看——这一步特别重要。 |
| 5 秒讲清内容 | 介绍主题和内容时尽量直接明了，不塞无关信息；东拉西扯只会消耗耐心，最好每一句话都有作用。 |
| 8 秒设置转折 | 能调动情绪的内容已成功一大半；之后可每隔约 9 秒安排一次转折，连续的变化让观众保持期待。 |

## 三、表达原则

做短视频不是在讲专业课，用户刷内容也不是来上课的——表达尽量**口语化**，把复杂的话说简单，不堆专业词，让人一看就懂，更容易拉近距离。

## 四、创作流程八步

1. 先定主题，再决定这条内容要拍给谁看。
2. 开头 3 秒先抓眼，别一上来就铺垫太久。
3. 镜头顺序提前写好，现场拍摄会轻松很多。
4. 场景、景别、角度，最好在脚本里一次想清楚。
5. 旁白和字幕分开准备，后期处理会更顺手。
6. 单镜头别拖太长，节奏清楚观感才舒服。
7. 套用模板填空，比临场发挥更稳定。
8. 给一个关键词，也能快速生成一版脚本思路。

## 五、脚本模板（表格列定义）

| 列 | 填写要点 |
|---|---|
| 标题 | 先确认这条内容的中心和主题，后面的镜头与表达都围绕这个重点展开。 |
| 拍摄场景 | 根据主题安排对应拍摄地点，让场景和内容保持一致。 |
| 镜号 | 按内容推进的先后排列镜头顺序，后期剪辑更清楚。 |
| 画面内容 | 把每一镜要呈现的动作、物体或情境直接写出来，执行时更明确。 |
| 景别 | 远景、全景、中景、近景、特写搭配使用，让画面更丰富、内容更完整。 |
| 角度 | 平拍、俯拍、仰拍、侧拍交替运用，增强变化感。 |
| 字幕 | 重点信息提前整理，字幕更精简也更容易阅读；重点内容可用更醒目的字幕样式补充。 |
| 旁白 | 需要说的话提前准备好，现场收音或后期配音都会更顺畅。 |
| 音效 | 按画面气质选择合适的背景音乐或环境音，增强氛围表达。 |
| 时长 | 提前规划每个镜头和整体时长，拍摄节奏更稳。 |

## 六、视频定位参考（赛道选择）

| 定位 | 要点 |
|---|---|
| 学习成长 | 记录备考、技能提升或学习过程，把经验讲清楚更容易留下价值。 |
| 美食分享 | 拍家常菜、备餐过程或探店记录，主题明确更方便展开。 |
| 穿搭灵感 | 适合喜欢搭配的人，先定风格，画面会更统一。 |
| 日常记录 | 从真实生活里找重点，主次清楚，更容易拍出记忆点。 |

## 七、标题与拍摄准备

- **标题**：简短直给——用清楚的关键词点明核心，让人一眼就知道这条内容讲什么。
- **拍摄地点**：先确认场景（家里/户外/门店），与主题相匹配。
- **节奏**：可以偏快也可以偏慢，但说话和画面都要稳，不要杂乱。
- **日期**：提前定好拍摄时间，方便安排光线、服装和道具。
- **周围环境**：提前整理背景减少杂乱，整体观感更舒服。
- **人物动作**：把需要做的动作先想好，拍摄时不容易反复重来。

## 八、时长参考

| 项 | 口径 |
|---|---|
| 总时长 | 整体控制在 2—5 分钟内，信息完整但不拖沓。 |
| 单镜头 | 每个镜头尽量保持 3—10 秒，更利于节奏安排。 |
