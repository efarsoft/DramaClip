# 经验库（外部经验/技巧归档）

收录业主提供的外部经验与技巧，**只收整理后的 Markdown**——截图/原文一律不归档，由整理者重写为结构化知识。

## 收录纪律

1. 只保留可执行的经验本体：去噪、去排版装饰、合并重复项。
2. 按主题一个文件，后续同类经验并入既有文件；新主题新建文件并更新本索引。
3. 文件用中文命名，正文结构化（表格/清单），经验条目保留原始量级口径（如「3 秒」「2—5 分钟」）。
4. 不标注外部来源渠道名。
