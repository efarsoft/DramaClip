# ASR×OCR 融合转写质量报告

> 2026-09-11 · 验收剧《小小球神不好惹》第 1 集（192s，1080×1920）· faster-whisper small（CPU）

## 1. 结论

| 指标 | 数值 |
|------|------|
| 融合前 ASR 字符错误率（CER） | **18.1%** |
| 融合后 CER | **2.8%** |
| 相对降幅 | **85%** |
| 变差段 | **0** |
| 段级来源分布 | 纯 ASR 34 / OCR 校对 29 / 待人工复核 7 |

目标"错字率打下来"达成：对白文本达到与人工字幕（硬字幕）基本一致的水平。

## 2. 方法

- **金标准**：硬字幕 OCR 条（字幕组人工校对文本，经条合并与繁简归一）。
- **融合前文本**：从段级 word 时间戳重建（字级 words 即原始 ASR 输出）。
- **CER**：`1 − SequenceMatcher 相似度`，双方去标点去空白后计算。
- 覆盖段 69/79；其余 10 段为旁白/画外音（无字幕覆盖，无金标准，不参与）。

## 3. 融合决策表（fusion.py）

| 情况 | 裁决 |
|------|------|
| OCR 与 ASR 一致 | 直接采用 |
| 不一致，ASR 字概率 ≥0.92 且 OCR 置信 <0.75 | ASR 翻案（字幕组错字/艺术字误识） |
| 其余不一致 | 默认信 OCR（人工校对文本） |
| 仅 OCR 有（BGM 段 ASR 漏字） | OCR 补齐 |
| 仅 ASR 有（旁白/画外音） | ASR |
| 分歧双方均低置信 | 标记 `review` 进人工复核（不猜） |

## 5. 诚实披露

- 残余 2.8% 误差主要来自**片头新闻蒙太奇段**：快速切镜 + 动效字导致 OCR 采样到半帧
  （"coocoa"类水印/歌词残留），此类段已标记 `review`，由工作台行内编辑人工处理，
  不静默带错。
- 金标准本身取自 OCR——本剧字幕为标准底部白字（对 OCR 最友好场景）；艺术字/竖排
  字幕剧的收益预期会低于本报告数值，待更多剧验证。
- 3 例"叠字"缺陷（你你是谁）在真机验证中发现并修复：根因是 whisper 词为多字 token，
  与 OCR 单字对齐粒度不对等——词炸成单字单元后归零。

## 6. 成本

- OCR 通道：~85s/集（CPU，1fps + 底部 ROI）；全剧两阶段先行，与 ASR 无重叠。
- word_timestamps 使 ASR 转写增加约 10~20% 耗时（GPU 路线打通后收回）。
- 人工复核量：7/69 段（10%），行内编辑 + 重跑语义闭环已有。
