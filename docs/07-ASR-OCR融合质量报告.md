# ASR×OCR 融合转写质量报告

> 2026-10-10 复核 · 验收剧《大明：灭国前，我觉醒了》第 1 集（66s，真值 207 字人工标注）· paraformer + RapidOCR
> 本文记录「谁供文本、谁供时间」这条分工是怎么被实测定下来的，以及当前真机读数。2026-09-11 初版报告（《小小球神不好惹》）已作废，作废理由见 §6。

## 1. 结论

| 指标 | 数值 |
|------|------|
| 纯 ASR 字符错误率（CER） | **11.1%** |
| 融合后 CER | **11.1%**（文本一字未被改写） |
| 字幕条 → 面板行 | 27 → 23（4 条无语音逐字佐证，删除） |
| 行时间重叠 | **0**（行时间取条驻留窗，窗互不重叠） |
| 段来源分布 | 无徽标 17 / `review` 6 / `ocr_fixed` 0 |
| 字数守恒 | 输出 208 字 vs 真值 207（ASR 自身 1 处插入，融合不吞字也不造字） |

融合**不改文本**，只改分行与时间——CER 与纯 ASR 相等是设计目标，不是缺陷：文本侧的错要由人工复核或上游识别链路解决，不许由 OCR 代改。§5 列这条设计留下的遗留，§6 记录时间轴侧本轮修掉的缺陷。

## 2. 分工判据（实测，不是偏好）

207 字人工标注逐位判定「这一位 ASR 对 / OCR 对 / 都对 / 都错」：

- **文本主干 = ASR**。两通道分歧时 ASR 独对 12.1%、OCR 独对 5.8%（约 2:1）；纯 ASR CER 11.1% 对纯 OCR 抄写 41.5%。OCR 的错是字形误读（崇桢/蛙虫/枚势滔失/锦衣工头子），根本不是汉语词；语音侧的错是同音字，保留词形，人工一眼可辨。
- **时间与分行 = OCR**。paraformer 是 VAD 连续语音引擎，本集整集只出 **3 条巨段**（0.8–13.6 / 18.1–44.7 / 45.5–65.8），句级边界只能来自字幕条驻留窗。字级戳是把整段时长均分的插值（seg2 实测 1.0 s/字），与画面字幕窗对账**中位差 1.98s、最大 7.75s 且方向会翻转**——所以任何「用时间去挑条/下刀」的写法都会把词劈开（真机「大明两」「权势滔天贪」「生我比」）。
- **置信度不参与裁决**。paraformer 无字级概率（`WordSpan.probability` 633/633 实测恒等 1.0），靠概率翻案的判据形同虚设；RapidOCR 条置信中位数 0.758，也分不出对错。
- **帧多数表决不降噪**。同一条字幕按帧多数表决重读，本集误读 30.9% → 29.5%，基本没动，故未采纳。

## 3. 现行裁决规则（与 `fusion.py` 一一对应，勿在别处复述）

| 情况 | 裁决 |
|------|------|
| 一条字幕获得 ≥1 个逐字相同的语音字 | 成为面板一行：文本取 ASR 字，时间取该条驻留窗 |
| 一条字幕一个字也没被语音逐字佐证 | 删除，不产行（2026-10-10 业主裁定「无佐证条删除」） |
| 语音字在配对里咬住的正是被删条 | 回挂前一条（行首孤字前挂第一条），并把吞下的字数计入**那一行**的分歧距离 |
| 一行对不上的字数（错配 + 无佐证的 OCR 字 + 吞下的误读字）≥ 2 | 标 `review` 交工作台人工；单字差多是字形误读，不刷徽标、更不改字 |
| 整段语音恰好全落在同一条字幕上，且该条还有语音侧没有的字 | 才允许 OCR 补字并标 `ocr_fixed`；拆出来的行只覆盖巨段一截，一律不补 |
| 标点 | 不进对齐流，拼行时按原位置随字回插 |
| 任一段的字级戳与文本对不上 | 整集回落到未融合 ASR 段并记 `warn`——宁可不分行，不许丢字或凭空造字 |
| 全片无一条获得逐字佐证 | 整集回落到 ASR 并记 `warn` |

## 5. 已知遗留（已立案，未修）

- **台词空洞**：无佐证条删除后，那一秒画面有字、面板无行；擦除仍覆盖**全部**条窗，所以成片表现是「源字擦掉、新字缺席」。本集实测 4 处、合计 5.5s。→ 立案③
- **OCR 字形误读回灌热词**：误读串会被热词挖掘选成热词，是否加黑名单闸待裁定。

## 6. 时间轴侧：烧录时钟已归一到行窗（2026-10-10，原立案④＝任务 #121/#123）

**原缺陷**：擦除挂 delogo 按字幕条驻留窗，烧录台词行的时刻却按 ASR 词戳——同一集两套时钟。《大明》第 1 集走生产裁剪函数实测：起差中位 **3.80s**、最大 **13.34s**，23 行里 **16 行的烧录时刻与行窗重叠为 0**（源字幕在屏时我们的字不在，反之我们的字在屏时源字幕已被擦掉）；整行词戳都落在段窗口之外时，那一句台词**整行从成片里消失**。

**修法**（`export.crop_dialogue_lines`）：行窗（=融合行的条驻留窗，与擦除同源）是唯一显示时钟，词戳只定「哪些词属于本段」和行内节奏。归属前把该行词戳跨度仿射贴合到行窗（`t' = s + (t − W0)·(e − s)/(W1 − W0)`），行内比例保留、绝对时刻换成字幕窗。修后本集重测：起差/止差 **0.00s**，重叠率中位 **1.00**，完全错开的行 **0/23**，23 行全部保住。

**为什么没有拦片静态闸**（原计划的「时间轴静态闸」被实测否掉）：真机库内 10 集 272 行有 **24 行（8.8%）落在所有驻留窗之外，且属正常**——纯 ASR 行/画外音本就没有屏上对应物，十集全中。把这条度量当判据就是重演覆盖闸包含式判据拦下 8/10 集的错误。改成出片记一条 info 明账（`_clock_audit` / `_log_clock_audit`）：烧录几行、几行与驻留窗零重叠；该剧没有驻留窗时记「未对账」，不许记成对上。

## 7. 初版报告（2026-09-11）作废说明

《小小球神不好惹》第 1 集 / faster-whisper small 的「18.1% → 2.8%、相对降幅 85%」与「默认信 OCR，ASR 字概率 ≥0.92 且 OCR 置信 <0.75 才翻案」决策表，被 §2 的实测整体推翻：

- 那条决策表的两把尺子都不存在——paraformer 侧字概率恒 1.0，OCR 侧置信分不出对错。
- 2.8% 是「拿 OCR 抄 OCR」的自证：金标准就是被测物本身，文本向金标准靠拢是改写的直接后果，不是识别变准。
- 口径不可比：该文 CER 用 `1 − SequenceMatcher 相似度`（匹配块口径），同一文本在去标点 Levenshtein 口径下高 3 个百分点（8.2% vs 11.1%）。本文 CER 统一定义为：**去标点去空白后 Levenshtein 距离 ÷ 真值字数**。任何新读数只准用这一条口径，跨报告比对先换口径。

原文数值不再作为任何决策依据，此处只留两条教训：**金标准不得是被测物**；**同一含义不得有第二个口径**。
