DramaClip 完整UI设计方案（深色科技感版）

一、设计理念

DramaClip是一款AI驱动的短剧视频智能剪辑工具，面向内容创作者和短视频运营人员。视觉设计以深空灰为基底、电光蓝为功能主色，通过克制的发光效果和精密的信息层级，传达"AI驱动、专业生产力"的产品心智。

核心设计原则：

沉浸专注：深色背景减少视觉干扰，让视频预览和编辑内容成为焦点
信息分层：通过背景色深浅、文字明度、边框有无构建清晰的信息层级
克制发光：微光效果仅用于关键交互反馈和状态强调，不滥用
高效操作：所有操作路径最短化，减少点击层级，支持快捷键

二、全局框架

2.1 窗口规格

默认窗口尺寸：1280 × 800
推荐窗口尺寸：1920 × 1080
最小窗口尺寸：1024 × 680（minWidth=1024，使第十章 <1280 / <1024 两档响应式断点可生效）
标题栏：跟随操作系统原生样式（Windows为系统标题栏，macOS为红绿灯按钮区域）；主进程设置 nativeTheme.themeSource='dark'，保证 Windows 原生标题栏与深色 UI 一致
