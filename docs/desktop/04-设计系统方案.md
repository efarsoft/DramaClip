# DramaClip UI 设计系统方案（DSS v1）

> 目标：**任意两个页面截图放在一起，看不出是两拨人写的。**
> 本文档是唯一的视觉真相源。组件内禁止裸写 fontSize / borderRadius / 间距数值。

---

## 0. 对标定位

密度与气质对标：**剪映专业版（布局骨架）× Notion（留白与层级）**。
深色科技感但克制——低饱和底色 + 一个主色 + 一个渐变强调，不发光、不霓虹。

## 1. Design Tokens（唯一真相源）

### 1.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `bg/base` | `#0F1115` | 侧栏/标题栏（最深层） |
| `bg/layout` | `#10141C` | 页面底 |
| `bg/container` | `#171C26` | 卡片 |
| `bg/elevated` | `#1F2634` | 悬浮层/下拉/输入框底 |
| `bg/input` | `#141922` | 输入控件 |
| `border/strong` | `#2A3140` | 主分隔线 |
| `border/subtle` | `#212736` | 卡片描边 |
| `text/primary` | `#EAEEF5` | 标题/正文主色 |
| `text/secondary` | `#9BA3B4` | 说明文字 |
| `text/tertiary` | `#626B7D` | 占位/辅助 |
| `brand/primary` | `#4D9FFF` | 主操作/选中态 |
| `brand/gradient` | `135° #4D9FFF → #7C5CFF` | Logo/强调条/主按钮 |
| `status/success` | `#34D399` | 就绪/完成 |
| `status/warning` | `#FBBF24` | 缺配/注意 |
| `status/error` | `#F87171` | 失败 |
| `status/info` | `#60A5FA` | 进行中 |

**语义色使用规则**：状态点的颜色永远来自 `status/*`，卡片/分区图标允许用
`status` 系以外的装饰色，但同一页面内装饰色不超过 3 种。

### 1.2 间距（4 的倍数，8pt 栅格）

| Token | 值 |
|---|---|
| `space/xs` | 4 |
| `space/sm` | 8 |
| `space/md` | 12 |
| `space/lg` | 16 |
| `space/xl` | 20 |
| `space/2xl` | 24 |
| `space/3xl` | 32 |

**节奏规则**：页面纵向节奏一律用 `xl(20)` 或 `2xl(24)`；卡内元素间距一律
`sm(8)` 或 `md(12)`；禁止出现 10/14/18/22 等非栅格值（现有代码大量存在，迁移时清零）。

### 1.3 字号体系（消灭 12.5/13.5 魔法数）

| Token | 值 | 用途 |
|---|---|---|
| `font/title-lg` | 22 / 700 | 页面主标题 |
| `font/title` | 15 / 600 | 卡片标题/分区标题 |
| `font/body-lg` | 14 / 400 | 重要正文 |
| `font/body` | 13 / 400 | 默认正文（全局默认） |
| `font/caption` | 12 / 400 | 说明/帮助文字 |
| `font/micro` | 11 / 400 | 角标/芯片/时间码 |

### 1.4 圆角与层级

| Token | 值 |
|---|---|
| `radius/card` | 10 |
| `radius/control` | 8（按钮/输入框） |
| `radius/chip` | 999（胶囊） |
| `radius/thumb` | 6（小缩略图） |
| `elevation/card` | 无阴影（描边即层级） |
| `elevation/hover` | `rgba(77,159,255,0.08)` 背景 + 主色描边 |
| `elevation/pop` | `0 8px 24px rgba(0,0,0,0.45)`（下拉/弹窗） |

## 2. 布局骨架（唯一合法页面结构）

```
┌────────────────────────────────────────────────┐
│ TitleBar（46px，全局）                          │
├───┬────────────────────────────────────────────┤
│ R │ PageShell（maxWidth 1080 居中）             │
│ a │  ┌ PageHeader ────────────────────────┐    │
│ i │  │ title + desc      [actions 槽]     │    │
│ l │  └────────────────────────────────────┘    │
│   │  ┌ PageSection（title 可选）──────────┐    │
│ 68│  │ …内容…                              │    │
│ px│  └────────────────────────────────────┘    │
│   │  [PageFooter 固定底栏，仅向导页]           │
├───┴────────────────────────────────────────────┤
│ StatusBar（26px，全局）                         │
└────────────────────────────────────────────────┘
```

### 2.1 PageShell
- `maxWidth: 1080`，水平居中，垂直节奏 `2xl(24)`
- **全屏型页面**（分析工作台）例外：`fullbleed` 模式，去 maxWidth，纵向节奏 `xl(20)`
- 不接受任意 style 覆写

### 2.2 PageHeader（每页唯一）
```
[Back?] Title(title-lg)  ·副标题胶囊·     [secondary action][primary action]
        desc(caption, tertiary)
```
- 主操作（保存/开始出片）放右上 **primary**；次操作（还原/全选）放其左 **secondary**
- actions 随滚动**吸顶**（工作台向导页与设置页必须）

### 2.3 PageSection
- 标题行：`3px 渐变竖条 + title(15/600)`，可选右侧 extra 槽（文字链/开关）
- 卡片内边距 **16（ lg ）**统一；列表型 section 内边距 0、行内 12

### 2.4 PageFooter（向导页专用）
- 高 46，`bg/base`，上描边；左：上一步；中：步骤进度文案；右：下一步（primary）

## 3. 组件规范

### 3.1 按钮
| 层级 | 样式 | 用途 |
|---|---|---|
| primary | `brand/gradient` 底白字 | 每屏**至多 1 个**（保存/开始出片/下一步） |
| secondary | 描边 + `bg/elevated` | 还原/全选/批量操作 |
| ghost | 纯文字 `brand/primary` | 行内链接动作（去调整/查看作品→） |
| danger | 红 600 底 | 删除 |

高度统一 32（小）/ 36（默认）。

### 3.2 表单字段行（设置类页面唯一结构）
```
标签(body)                ┌──────────────┐
帮助文字(caption,tertiary) │ 控件(280 固定宽) │
                         └──────────────┘
```
- 标签列固定 200，控件列固定 280，行高以 `md(12)` 上下留白
- 行间用 `border/subtle` 分隔，末行无

### 3.3 状态点与徽章
- 状态点：6px 圆 + 同色 `0 0 6px` 微光（就绪/缺配/失败/进行中）
- 信息芯片：`radius/chip` + `font/micro`，例：`10 集`、`已选 2/9`
- 能力徽章（含 AI 文案/含 AI 配音/无需文案）：胶囊描边式，绿=有、灰=无

### 3.4 卡片
- 一律 `bg/container` + `border/subtle` + `radius/card`
- 悬浮态统一 `elevation/hover`（背景 + 主色描边，不是阴影）
- 图文卡（作品/项目）：封面区固定比例，信息区 padding 12

### 3.5 空态
图标（48，tertiary 40% 透明）+ 一句话 + （可选）primary 行动按钮。全局用同一组件。

## 4. 信息架构重排（迁移时同步做）

### 4.1 偏好设置
分区图标：🎯 智能分析 / 💬 字幕 / 🎬 出片 / ⚙️ 硬件。
保存栏吸顶；分区按「使用频率」排序：出片 → 分析 → 字幕 → 硬件。

### 4.2 引擎中心
- 左侧 tab 栏改为「图标+文字」列表卡，选中态 = 主色左条 + 8% 主色底（和素材列表行同构）
- 三能力卡加图标：🎙️ / 🔊 / ✍️；本地引擎区用 success 色系点缀、云端用 brand 色系点缀
- 模型行、参数行统一字段行结构

### 4.3 工作台
- 问候头 + 4 统计芯片 + 2×2 开始创作 + 右栏（环境/工具/上手）全部对齐 8pt 栅格
- 环境就绪度行结构与素材列表行同构（点=状态、右=ghost 链接）

### 4.4 作品库 / 项目页
- `WorkCard` / `ProjectCard` 收敛为一套卡片 mixin；模式徽章色环固定 6 色

### 4.5 出片中心
- 风格选择卡与模式选择卡同宽同构；出片记录行 = `Tag + 名称 + 右侧 meta` 通用行
