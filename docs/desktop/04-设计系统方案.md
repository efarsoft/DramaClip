# desktop/04 · 设计系统方案（DSS v2.0 · 靛青雾面）

> 唯一真相源：`desktop/src/styles/theme.ts`（token）→ `styles/mixins.ts`（版式函数）→ `components/layout/PageKit.tsx`（页面骨架）。
> 组件禁止裸写 fontSize / borderRadius（eslint 拦截）；颜色与间距一律引用 token，1/2/3px 为光学微调豁免。

## 1. 设计原则

1. **亮度分层**：层次靠背景亮度差（sidebar < layout < container < elevated），不靠 1px 边框硬撑。
2. **内容优先**：中性深底让视频缩略图/封面最显色；彩色只留给主色、状态与内容。
3. **数据可读**：数字一律等宽字体（JetBrains Mono / Cascadia / Consolas），大数字 24-26px。
4. **缺席而非假控件**：能力未实装不渲染入口；取不到的状态显示"—"不显示 0。
5. **栅格**：内容页 1320 流式（narrow 880 表单/文本页）；间距 4 的倍数；1/2/3px 光学微调豁免。

### 2.3 间距 / 圆角 / 投影 / 布局

- 间距 4 倍数：spaceXs 4 / Sm 8 / Md 12 / Lg 16 / Xl 20 / 2xl 24 / 3xl 32。
- 圆角：radiusCard **14** / radiusControl **10** / radiusThumb 6 / radiusDot 3 / radiusChip 999。
- 投影：`shadowCard 0 6px 20px rgba(4,8,20,.35)`（PageSection 必带）、`shadowPop 0 12px 32px`（浮层）。
- 布局：**全站统一铺满**（无页宽上限，内容随窗口拉伸）；railWidth 68。

## 3. 版式函数（mixins.ts）与页面骨架（PageKit.tsx）

- **PageShell**：内容页与向导页统一铺满（无锁宽）；AppLayout main 统一 20/24 内边距。
- **PageHeader**：标题（22/700）+ 描述（12 tertiary）+ 右侧动作槽；**每屏 primary 至多 1 个**；空态时 primary 让位给空态引导。
- **PageSection**：分区卡（container 底 + border + shadowCard + radiusCard 14）；标题行 = 渐变竖条 + 15px/600 + extra 槽。
- **fieldRow v2**：标签列 250（标题 13 主色 + 帮助 11 tertiary 上下组合、顶对齐）+ 控件列 320 + gap 24；**无行分隔线**。
- **listRow**：行高统一（8 12 内边距）、hover bgElevated、可点击项必须带动作。

## 4. 组件模式

- **海报网格**（成品/媒体类内容）：`repeat(auto-fill, minmax(230px,1fr))` 流式列；16:9 封面无描边；hover scale(1.02)+shadowPop；左上模式标签、右下等宽时长角标、底部渐变承托。
- **内联数据芯片**：38px accentSoft 圆角图标 + 26px 等宽大数字 + 下方 micro 标签 + 注脚右置；无卡片壳。
- **继续上次（hero 条）**：72×44 封面缩略图 + 「继续上次/剧名」层级 + 右侧相对时间与箭头。
- **待办条**：状态点（status 色）+ 结论文本（detail 挂 title 不截断）+ ghost 动作按钮；空数组整块缺席。
- **空态**：48px 图标（accentSoft 底）+ 一句话 + 唯一 primary；虚线边框占位条。
- **覆盖层**：遮罩 rgba(4,6,12,.62)，Esc/点遮罩关闭，永不自动弹出。

## 5. 状态与色彩语义

- 状态点/文字三档：error #F87171、warning #FBBF24、info #60A5FA；**#FF4D4F 为钩子语义专用**。
- 「取不到」显示 **—** 并附原因（如 jobs 不可用 → 芯片 '—' + jobs-unavailable 待办），**禁止把不知道说成没有**。
- 文案纪律由 `src/__tests__/copyTruth.test.ts` 门禁：禁「降级为关键词/自动降级/后续版本/绕过平台/网盘/即将」等承诺性与违禁子串。
