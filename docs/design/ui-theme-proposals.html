方案 A · 靛青雾面Refined Indigo

保持深色，但把"硬边框盒子"换成"亮度分层 + 柔和投影"：卡片比背景亮一档、14px 大圆角、外阴影替代部分描边。主色往靛青偏移更贵气；标题字号加大、芯片数字改 22px 等宽——层级感是这一版的关键词。气质参照 Linear / Raycast。

方案 B · 石墨专业台Graphite Pro

去蓝取灰：背景全部转中性石墨，蓝色只留给内容与状态——视频缩略图在这样的底上最显色。8px 小圆角 + 更紧凑的密度，专业剪辑台（Resolve / Premiere）的冷静气质。主色换青绿以拉开与竞品的辨识度（也可保守回退蓝色）。

方案 C · 晨雾浅色Daylight
