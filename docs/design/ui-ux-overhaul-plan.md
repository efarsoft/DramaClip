## 七、新增功能：成片详情页 + 候选标题（2026-09-16 设计定稿，待实施）

**入口改造**：作品库卡片/首页海报 → 详情页 `/works/:exportId`（替代预览弹窗）；出片记录行也可点入。

**页面结构（左右布局）**：
- 左：9:16 播放器（大，含播放控制）
- 右上：元数据卡（模式/时长/大小/分辨率/编码/创建时间/输出路径+打开文件夹）
- 右下①解说文案：逐段列表（段号/文本/时长/音色），全文复制+逐段复制
- 右下②候选标题：LLM 生成 5-10 条（每条带复制；可标记采用），未生成显示生成按钮，支持重新生成
- 页头动作：删除（P-3.3 回收站语义到位后启用）

**数据与工作流调整**：
1. 迁移 012：narration_plans 加 `titles` TEXT（JSON 数组 [{text, selected}]）——标题归属方案而非导出（一案一导出现实）
2. 新 RPC `narration.generate_titles`：plan_id → LLM 读该方案 narration_texts 全文 → 生成候选标题落库；**手动触发**（不自动生成，避免每案必烧 LLM）
3. 出片完成工作流不变；详情页读取 plan_data + titles 渲染
4. 协议：TitleCandidate/PlanTitles TS+schema；METHOD_NAMES +2（generate_titles/titles 读写随 list_plans 扩展或独立 get）

**工作量**：约 1 天（迁移+2 RPC+详情页+入口改造+测试）。


## 八、渲染/编排质量专项（2026-09-16 立案，最高优先）

用户重跑九模式后实测发现 5 个质量问题（截图在案），成品已全部删除待修复后重验：

1. **字幕遮罩位置不对**：解说字幕烧录位置超出画面底缘（截图：字幕下半被裁）。排查 ass_generator 的 MarginV/对齐与 9:16 out_size 的关系；遮罩（mask）如涉及也一并核对。
2. **解说文案字幕混乱**：narration_texts 整段直接作为单条字幕，无分段、标点原样、单行超长溢出画面。需要：转写/文案侧按 ≤16 字两级分段+标点清理；ass 侧按行拆分时间轴。
3. **跳帧行为**：成片播放中突然卡顿后跳新场景。排查 concat 段边界时间戳、atempo/去重抖动参数、段内 end 越界（记忆：safe_times 裁剪逻辑）。
4. **无语音避让**：解说与原声同音量叠放。ducked 分支（0.5 已实现）疑似未在新编排链路生效——排查 timeline 段 audio 标记与 cut_segment_args 的 ducked 路径，确认 narration 模式下 original 段全部 ducked。
5. **成片时长过短**：策略上限 300s 但成片 16s-4:46 不等。排查编排侧场景预算选择（是否只取了少量高分场景）、TTS 时长回填后的时长约束逻辑。

**处置顺序**：4（语音避让，功能性硬伤）→ 2（文案分段）→ 1（遮罩位置）→ 3（跳帧）→ 5（时长策略）。
2/3/4 都在 exporter/encoder 与 narration pipeline 侧，预计 1-1.5 天；5 需编排策略审读另计。


## 九、引擎中心诚实性修复 + TTS 引擎接入缺口（2026-09-16 业主指出）

**现状误导**：TTS 模型库显示 IndexTTS2/VibeVoice「已安装」，但合成引擎未实现——装了也无法启用，无任何入口或提示。ASR 无此问题（默认模型下拉即改即存，faster-whisper 全系支持）。

**修复（UX 诚实性，随下批 UI 落地）**：
- TTS 模型行：Kokoro=「引擎已接入」；IndexTTS2/VibeVoice=灰色「引擎未接入 · 仅存储」徽章，替代误导性的"已安装"
- 行内说明：合成引擎接入后排期见 P-2

**引擎接入（大项，独立排期）**：
- IndexTTS2：零样本音色克隆（需参考音频上传/录制链路 + gpu 显存门槛标注）
- VibeVoice 1.5B：多角色对话配音（双人对谈模式的升级路径）
- 完成后模型行自动获得「启用」动作
