## 七、新增功能：成片详情页 + 候选标题（2026-09-16 设计定稿，待实施）

**入口改造**：作品库卡片/首页海报 → 详情页 `/works/:exportId`（替代预览弹窗）；出片记录行也可点入。

**页面结构（左右布局）**：
- 左：9:16 播放器（大，含播放控制）
- 右上：元数据卡（模式/时长/大小/分辨率/编码/创建时间/输出路径+打开文件夹）
- 右下①解说文案：逐段列表（段号/文本/时长/音色），全文复制+逐段复制
- 右下②候选标题：LLM 生成 5-10 条（每条带复制；可标记采用），未生成显示生成按钮，支持重新生成
- 页头动作：删除（P-3.3 回收站语义到位后启用）

**数据与工作流调整**：
1. 迁移 012：narration_plans 加 `titles` TEXT（JSON 数组 [{text, selected}]）——标题归属方案而非导出（一案一导出现实）
2. 新 RPC `narration.generate_titles`：plan_id → LLM 读该方案 narration_texts 全文 → 生成候选标题落库；**手动触发**（不自动生成，避免每案必烧 LLM）
3. 出片完成工作流不变；详情页读取 plan_data + titles 渲染
4. 协议：TitleCandidate/PlanTitles TS+schema；METHOD_NAMES +2（generate_titles/titles 读写随 list_plans 扩展或独立 get）

**工作量**：约 1 天（迁移+2 RPC+详情页+入口改造+测试）。
