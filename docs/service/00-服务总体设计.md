# service/00 · Python 服务总体设计

> 服务端 = 独立 Python 进程（包名 `dramaclip`），承载全部业务与数据（ADR-006）。
> 线协议见全局 `03-IPC协议规范.md`；表结构见本文档目录 `04-数据模型.md`。

## 1. 进程职责

- 接收 Electron 主进程的 RPC 请求并响应（transport + api）；
- 执行全部业务引擎（分析 / 语义 / 解说 / 字幕 / 消重 / TTS / 策略 / 导出）；
- 独占 SQLite（迁移、读写、备份的唯一执行方）；
- 调度本地 FFmpeg 与 AI 模型，管理模型下载；
- 通过通知通道主动推送任务进度与日志。

**不做**：任何 UI 概念；任何网络服务（仅本地套接字客户端）；直接与渲染层通信。

## 2. 内部分层（依赖方向单向，禁止反向 import）

```
transport/   连接与信封（只认 api 暴露的方法表）
    ↓
api/         方法注册层（参数校验、job 编排、结果序列化）
    ↓
engines/     业务引擎（纯业务逻辑，互相之间仅经数据结构协作）
    ↓
infra/       基础设施（storage / ffmpeg / config / jobs / paths / model_manager）
```

违规示例（禁止）：`engines.analysis` import `transport`；`infra` import `engines`。

## 3. 启动流程（`__main__.py`）

```
1. 解析参数与环境：--address（或 DRAMACLIP_PIPE_ADDRESS）；
   DRAMACLIP_AUTH_TOKEN、DRAMACLIP_DATA_DIR（缺失 → 退出码 2，stderr 说明）
2. infra.paths 解析数据目录（建子目录）
3. infra.storage 连接 SQLite → 执行增量迁移
4. infra.config 加载设置（DB 覆盖默认值）
5. infra.jobs 启动清扫：上一会话遗留 running 任务按重入协议处置（见 03-基础设施）
6. transport 建立连接 → 发送 hello{token, versions}
7. 进入服务循环（读到 EOF / shutdown / SIGTERM → 优雅退出）
```

## 4. 线程模型

| 角色 | 说明 |
|------|------|
| 读线程（transport） | 阻塞读管道，逐行解析，分发：request → 线程池执行；response 不会出现（客户端角色） |
| 写锁（transport） | 所有下行（response/notification）经同一把锁，保证行原子性 |
| 执行池 | `ThreadPoolExecutor(max_workers=settings hardware.max_parallel_jobs)`，执行引擎任务 |

**长任务一律 job 模式**：api handler 只做"创建 job → 提交执行池 → 立即返回 `{job_id}`"；耗时执行在池内进行，进度经 notify 推送。**禁止**在 handler 内同步执行超过秒级的工作（会阻塞同连接上的心跳）。

## 5. 优雅退出

- 触发：`system.shutdown` 请求 / 读到 EOF（连接断开）/ SIGTERM；
- 步骤：停止接收新请求 → 等待执行中 job 完成（上限 5s，超时标记 interrupted）→ 提交事务、关闭 DB → exit 0；
- Electron 侧 3s 超时后会强 kill，因此 5s 内未完成即放弃收尾。

## 6. 日志

- 进程日志写 stderr（Electron 收集到主进程控制台/文件）；
- 面向用户的关键事件（任务开始/完成/失败、模型下载）额外经 `log.append` 通知推送 UI；
- 轮动文件日志（`<data>/logs/`）P1 落地，W1 仅 stderr + 通知。

## 7. 错误处理分层

```
engines 抛业务异常（携带错误码段）
  → api 层捕获并转 RpcError（按域：-32100 项目 / -32200 分析 / -32300 剪辑 / -32400 导出）
    → transport 兜底：未捕获异常一律 -32603，异常详情进日志不回传（防泄漏堆栈）
```

## 8. 测试策略

- transport / api / infra：pytest 单测（连接层用内存对拍，LineAssembler 纯函数）；
- engines：纯逻辑为主（输入分析结果 JSON → 输出编排/参数），FFmpeg 相关用录制命令断言（不真跑编码）；
- 契约同步测试：Router.method_names ↔ schemas x-methods 集合相等；
- 覆盖率：engines 核心模块 ≥ 80%（04 规约）。
