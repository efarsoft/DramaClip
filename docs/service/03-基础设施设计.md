# service/03 · 基础设施设计（infra/）

> 被 engines 单向依赖；不感知 transport/api。表结构见 `04-数据模型.md`。

## 1. paths —— 数据目录

- 解析顺序：env `DRAMACLIP_DATA_DIR`（唯一来源，Electron 注入）→ 兜底 `%APPDATA%/DramaClip`（无 env 的裸跑场景，如调试）；
- 初始化子目录：`models/ cache/ outputs/ logs/`；
- 提供 `db_path() / models_dir() / cache_dir() / outputs_dir()` 访问器。

## 2. config —— 设置

- 默认值 = 代码常量 `DEFAULTS`（键清单见 04-数据模型 §3）；
- 启动时全量落库（不存在则写入），之后**以 DB 为唯一读取源**；
- 读取 API：`get_str/get_int/get_bool(key)`，类型转换失败回退默认值并告警；
- `settings.update` RPC 写库后调用 `reload()`，并广播 `settings_changed` 内部事件（engines 感兴趣的模块订阅，如 LLM 端点变更）。

## 3. jobs —— 任务状态机

```
pending → running → completed
              ├→ failed（error 落库）
              └→ cancelled
```

| API | 说明 |
|-----|------|
| `create(type, ref_id) → job_id` | 落库 pending |
| `mark_running / mark_completed / mark_failed(error) / mark_cancelled` | 状态迁移 + updated_at |
| `set_progress(job_id, percent)` | 进度落库（通知由 api 层的 ProgressReporter 另发） |
| `active_jobs() / get(job_id)` | 查询 |

**崩溃重入协议**（启动清扫，服务总体设计 §3 第 5 步）：

| 遗留状态 | 处置 |
|---------|------|
| pending | 保留，可被再次触发执行 |
| running | 标记 `failed`，error="服务中断"；analysis 类任务由 pipeline 断点续跑天然重入，导出类由用户重试 |

**并发控制**：执行池 `max_workers = hardware.max_parallel_jobs`（默认 2）；同类任务互斥（同项目同时只允许一个 analysis job）。

## 4. storage —— SQLite

| 组件 | 职责 |
|------|------|
| `db.py` | `connect(path)`：WAL + foreign_keys=ON + busy_timeout=5s；`migrate(conn)`：按文件名序号执行 `migrations/*.sql`，记入 `schema_migrations`（幂等） |
| `repos/*.py` | **表级仓储**：projects / episodes / prescreen / analysis / plans / exports / tts_cache / subtitle_presets / settings / jobs；引擎只允许经 repo 访问数据，禁止裸 SQL |

事务约定：repo 方法自带事务；跨表一致性场景（如 analysis 完成 写 episode_analysis + 更新 episode.status + 完成 job）由 api 层显式包裹。

## 5. ffmpeg —— FFmpeg 封装

| 组件 | 职责 | 要点 |
|------|------|------|
| `runner.py` | 进程执行 | args 列表构建（**禁止字符串拼接**，防注入/空格路径问题）；`-progress pipe:1` 解析出帧/时间→百分比回调；超时与取消（kill 进程组）；二进制路径解析：`resources/ffmpeg/ffmpeg.exe` → PATH |
| `probe.py` | ffprobe | 时长/分辨率/帧率/音轨元信息 → `MediaInfo` 模型 |
| `filters.py` | filtergraph 构建器 | 原语：`crop/scale/eq/setpts/atempo/ass/xfade/drawbox`；链式组装 + 逃逸（字幕路径含冒号等特殊字符处理）；dedup/mask/字幕烧录均基于此构建，**不手拼字符串** |

## 6. model_manager —— 模型管理

| 组件 | 职责 | 要点 |
|------|------|------|
| `registry.py` | 模型清单 | 内置清单（ASR：SenseVoiceSmall、faster-whisper 系列；TTS：Kokoro、IndexTTS-2）；条目 `{id, kind, repo_id, size_bytes, required?}`；`resolve(model_id) → 本地路径`（models/ 目录优先 → 缺失返回 None 触发下载提示） |
| `downloader.py` | 下载 | **ModelScope 默认源 → 失败降级 HuggingFace**（hf-mirror 镜像，经验参数表 §5）；断点续传；进度经 ProgressReporter 推送 `models.download_progress`；取消标志 |
| `importer.py` | 本地导入 | 用户选择本地模型目录 → 校验结构 → 登记到 models/（软链或记录外部路径） |
| 显存协作 | W5+ | ASR 与 TTS 不同时驻留：大模型加载前触发卸载钩子（v1 经验：7-8GB 显存机器会 OOM）；P1 落地完整策略 |
