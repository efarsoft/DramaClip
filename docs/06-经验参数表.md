# 06 · 经验参数表（v1 调优结论）

> 来源：初代原型实测调优结论（该版本代码已清理，仅存本表数据）。属于**实验数据而非代码**（ADR-003 例外条款）。
> 用途：v2 重写时的规格输入。数值可直接采用；标注"待复核"的项在对应功能落地时从 v1 源码核对补录。

## 1. 智能消重系统（v1: app/utils/ffmpeg.py）

### 台词保护区（Smart Jitter）

| 参数 | 取值 | 说明 |
|------|------|------|
| 保护区扩展 | 行首 -0.2s ~ 行尾 +0.15s | 有同名 .srt 时按每行字幕划定禁区 |
| 切点命中禁区 | snap 到禁区外边界 | 绝不吞字 |
| 安全抖动幅度 | ±0.08 ~ ±0.3s | 仅允许落在静音间隙内，相邻保护区为界，最外 ±3s |
| 无字幕降级检测 | 80ms chunk RMS，阈值 `max(均值×1.65, 120)` | 能量法语音区检测；最短语音段 0.28s |
| 抖动后最小片段 | 0.45s | 短于此回退原始切点 |

### 逐片段轻微处理（原案第八章）

| 参数 | 取值 | 手段 |
|------|------|------|
| 微变速 | 0.996 ~ 1.004 | `setpts=PTS/sf` + `atempo=sf`（变速不变调），音频重编码 AAC 128k |
| 微缩放 | scale_factor 0.982 ~ 0.988 | 先缩小裁切再等比拉回标准输出尺寸（约 1.2%~1.8% 变化） |
| 色彩抖动 | contrast 0.99~1.01，brightness ±0.01 | `eq` 滤镜 |
| 元数据擦除 | `-map_metadata -1` | 片段分割与最终拼接全程注入 |
| 选段去重 | 时间重叠 > 60% 的片段丢弃 | 选段阶段 |
| 抖动随机性 | 每片段独立随机 | 避免批量成品呈规律性 |

## 2. 高光打分权重（v1: analyze/scoring.py + clip/orchestrator.py）

| 场景 | 权重组合 |
|------|---------|
| 综合分析评分 | audio 0.38 / emotion 0.28 / visual 0.18 / rhythm 0.08 / speaker 0.08 |
| 原片直剪排序键 | audio 0.28 + visual 0.22 + rhythm 0.18 + score 0.22 + 稳定度奖励 0.25 − 运动惩罚（>0.72） |
| 混合解说排序键 | emotion 0.38 + audio 0.22 + dialogue_importance 0.32 + 稳定度 − 运动惩罚（>0.68） |
| 全解说排序键 | rhythm 0.42 + visual 0.28 + emotion 0.25 + 稳定度 − 运动惩罚（>0.70） |
